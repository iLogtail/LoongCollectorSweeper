## Summary

本 Issue 提议新增基于 C++ 的原生 Kafka Flusher 插件，旨在优化特定场景（如 Zstd 压缩）下的性能表现。当前 main 分支已提供基于 Go 的 kafka_v2 插件，但尚未实现原生 C++ 版本。社区讨论已明确关注性能收益与基准测试对比。该需求属于有效的核心插件扩展提议，尚无关联 PR 或替代方案，符合保守保留原则，建议保持开启以等待贡献者补充设计草案、性能数据及后续 PR。

## Best Possible Solution

保持开启。建议贡献者提供与现有 kafka_v2 插件的性能基准测试对比（特别是 CPU/内存与压缩场景），明确 C++ 客户端选型（如 librdkafka）及与 V2 Pipeline 的集成方案。待维护者确认架构兼容性与主仓库集成路径后，可提交 PR 进入审查流程。
