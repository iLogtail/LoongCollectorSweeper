## Summary

本 Issue 提议新增基于 C++ 的原生 Kafka Flusher 插件。当前 main 分支仅提供基于 Go 的 kafka_v2 插件，尚未合入 C++ 原生实现。社区讨论已关注其在特定压缩场景下的性能优势，属于有效的插件扩展提议。尚无关联 PR 或替代实现，符合主仓库插件贡献规范，建议保持开启以等待贡献者提交设计草案、性能基准对比及后续 PR。

## Best Possible Solution

保持开启。建议贡献者补充与现有 kafka_v2 插件的性能基准测试对比（特别是 CPU/内存与压缩场景），明确 C++ 客户端选型（如 librdkafka）及与 Pipeline 的集成方案。待维护者确认架构兼容性后，可提交 PR 进入审查流程。
