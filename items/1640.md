## Summary

本 Issue 请求为 Elasticsearch Flusher 增加 Data Streams 模式支持。经核查，当前 main 分支的 ES Flusher 仍基于传统 bulk index 操作，尚未实现 Data Streams 必需的 op_type: create 语义及索引命名规范适配。该需求属于核心插件的合理功能增强，且维护者已明确邀请社区贡献，无替代工单，故保持开启。

## Best Possible Solution

保持开启以跟踪该功能需求。建议贡献者在 Elasticsearch Flusher 中新增 DataStream 或 OpType 配置项，适配 ES Data Streams 必需的 create 语义与索引命名规范（如 logs-*-*）。实现时需修改 Bulk 请求头组装逻辑，将操作类型由 index 切换为 create，并补充集成测试。维护者可添加 help wanted 标签，或等待社区提交设计草案与 PR。
