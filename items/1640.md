## Summary

本 Issue 请求为 Elasticsearch Flusher 增加 Data Streams 模式支持。经核查当前 main 分支源码，官方 ES Flusher 的 Bulk 请求逻辑仍默认使用 index 操作，尚未提供 Data Streams 必需的 op_type: create 配置或索引命名适配。该需求属于现有核心插件的合理功能增强，维护者已明确邀请社区贡献，且无其他工单或 PR 替代实现，故保持开启以等待社区 PR 或维护者排期。

## Best Possible Solution

保持开启以跟踪该功能需求。建议贡献者在 plugins/flusher/elasticsearch 中新增 DataStream 或 OpType 配置项，适配 ES Data Streams 必需的 create 语义与索引命名规范（如 logs-*-*）。实现时需修改 Bulk 请求头组装逻辑，将操作类型由 index 切换为 create，并补充集成测试。维护者可添加 help wanted 标签，或等待社区提交设计草案与 PR。

## Evidence

- **implementation_gap:** 当前 Elasticsearch Flusher 的 Bulk 请求组装逻辑未提供 op_type: create 或 data streams 路由配置，功能尚未实现。维护者评论已确认需求有效并邀请贡献。
