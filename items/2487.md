## Summary

本 PR 修复了 metric_system_v2 插件中 fd 指标因 float64 导致的精度丢失问题，提议改为 string 类型。由于指标类型变更属于破坏性更新，且作者正文中主动提出了 uint64 或移除恒定值等替代方案，需维护者进行下游兼容性评估与技术路径裁决。当前 main 分支尚未合入该修改，保守评估建议保持开启。

## Best Possible Solution

保持开启等待维护者技术裁决。需评估将 fd 指标从 float64 改为 string 对下游监控系统（如 Prometheus/VictoriaMetrics）的兼容性影响。若确认采用 string 方案，请作者 Rebase 至最新 main 并补充单元测试与插件文档；若倾向 uint64 或移除恒定 fd_max，请指导作者调整实现路径。合并前需完成代码同步与 CI 验证。
