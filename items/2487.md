## Summary

本 PR 修复了 metric_system_v2 插件中 fd 指标因 float64 解析导致的精度丢失问题，但将指标类型从数值改为字符串属于潜在破坏性变更，需维护者评估下游兼容性或考虑 uint64 方案。当前 main 尚未合并此修复，且本 PR 需 Rebase 并补充测试，故保持开启等待审查。

## Best Possible Solution

保持开启等待维护者审查。建议维护者确认下游监控系统对字符串指标的支持情况，或指导作者改用 uint64 以保留数值语义。请作者 Rebase 至最新 main 分支，为 addMetricStringVal 及 fd 指标采集补充单元测试，更新插件文档说明类型变更，待 CI 通过后合并。
