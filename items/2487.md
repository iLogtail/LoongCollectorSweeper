## Summary

本 PR 提议将 metric_system_v2 插件的 fd_allocated 与 fd_max 指标从 float64 改为字符串上报，以解决 int64 最大值超出 float64 精度范围导致的数据截断问题。该修改涉及指标类型变更，可能影响下游监控系统的聚合查询与类型一致性，需维护者评估兼容性边界或决定是否直接移除恒定的 fd_max 指标。当前实现路径清晰但需架构决策与 Rebase，建议保持开启等待维护者审查。

## Best Possible Solution

保持开启并等待维护者审查。建议维护者评估下游系统对指标类型变更（float64 转 string）的兼容性影响；若需保留数值语义，可确认底层是否支持 int64/uint64 上报，或采纳 PR 正文建议直接移除恒定的 fd_max 指标。若确认字符串方案可行，请作者 Rebase 至最新 main 分支并补充单元测试后合并。
