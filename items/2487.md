## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 与 fd_allocated 指标因使用 float64 导致的大数值精度丢失问题。当前 main 分支仍存在该缺陷，PR 提供的字符串方案有效但涉及指标类型变更，需维护者评估下游兼容性或考虑 uint64 替代方案，故保持开启等待审查与合并。

## Best Possible Solution

保持开启等待维护者审查。建议维护者确认下游时序数据库与告警引擎对指标类型变更（float64 转 string）的兼容性；若数据管道支持，可评估改为 uint64 以保留数值语义。请作者 Rebase 至最新 main，补充对应单元测试验证大整数精度，CI 通过后由维护者合并。
