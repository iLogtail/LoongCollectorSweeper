## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 指标因 float64 精度限制导致的数据失真问题。当前 main 分支仍存在该缺陷，PR 提供了改为字符串上报的有效修复方案，需维护者评估下游类型兼容性后合并。

## Best Possible Solution

保持开启等待维护者审查。建议维护者评估下游监控系统对指标类型变更（数值转字符串）的兼容性；若需保留数值语义，可建议作者改为 uint64/int64 实现。请作者 Rebase 至最新 main 分支，补充相关单元测试，待 CI 通过后合并。
