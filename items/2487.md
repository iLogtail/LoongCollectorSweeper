## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 指标因 float64 精度限制导致的大整数丢失问题，提议改为字符串上报。该变更涉及指标类型转换，可能影响下游兼容性，需维护者审查决策。

## Best Possible Solution

保持开启并等待维护者审查。建议维护者评估下游系统对指标类型变更（float64 转 string）的兼容性影响；若需保留数值语义，可确认底层 Metric 结构是否支持 int64/uint64 上报，或采纳 PR 正文建议直接移除恒定的 fd_max 指标。若确认字符串方案可行，请作者 Rebase 至最新 main 分支并补充单元测试后合并。
