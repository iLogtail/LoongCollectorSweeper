## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 与 fd_allocated 指标因 float64 精度限制导致的大整数丢失问题，提议改为字符串上报。该变更涉及指标类型转换，需维护者评估下游兼容性并决策。

## Best Possible Solution

保持开启并等待维护者审查。建议维护者评估下游消费端对指标类型变更（float64 转 string）的兼容性影响；若确认字符串方案可行，请作者 Rebase 至最新 main 分支并补充/更新单元测试后合并。若下游强依赖数值类型，可考虑在 PR 中改用 int64/uint64 上报，或采纳移除恒定 fd_max 指标的替代方案。
