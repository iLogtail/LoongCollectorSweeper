## Summary

本 PR 提议将 metric_system_v2 插件的 fd 指标上报类型由 float64 改为 string 以修复大整数精度丢失。该变更涉及指标语义与类型的重大调整，可能破坏下游监控消费端的数值解析与告警逻辑，且作者正文中明确提出了改用 uint64 或直接移除恒定 fd_max 的替代思路。当前实现方案尚未定论，缺少针对类型变更的单元测试与兼容性说明，需维护者进行技术裁决与产品边界评估。保守评估建议保持开启。

## Best Possible Solution

维护者需评估 float64 转 string 对下游监控系统的兼容性影响。若确认采用 string 方案，请作者 Rebase 至最新 main 分支，补充或更新对应单元测试，并更新插件文档说明类型变更；若倾向 uint64 或移除恒定 fd_max 的替代方案，请指导作者调整实现。当前保持开启等待技术裁决与代码同步。
