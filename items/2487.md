## Summary

本 PR 针对 metric_system_v2 插件中 fd_max 指标因 float64 转换导致精度丢失的问题提出了有效的修复方案（改为字符串上报）。当前 main 分支仍存在该精度缺陷，且修改指标数据类型涉及下游监控系统兼容性评估，需维护者人工审查决策。

## Best Possible Solution

保持开启等待维护者审查。建议维护者评估下游对指标类型变更（数值转字符串）的兼容性影响；若需保留数值语义，可探讨改用 int64/uint64 上报或按需移除该常量指标。请作者 Rebase 至最新 main 分支，补充相关单元测试，待 CI 通过后合并。
