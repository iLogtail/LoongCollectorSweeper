## Summary

本 PR 提议将 metric_system_v2 插件的 fd_allocated 与 fd_max 指标类型由 float64 改为 string，以修复 int64 最大值导致的精度丢失问题。作者同时在正文中提出使用 uint64 或直接移除恒定值 fd_max 的替代方案。由于指标数据类型变更属于破坏性更新，直接影响下游监控系统（如 Prometheus/VictoriaMetrics）的查询与告警规则，且技术路径尚未收敛，需维护者进行兼容性评估与最终裁决。

## Best Possible Solution

保持开启等待维护者技术裁决。建议维护者评估下游兼容性：若接受 string 类型，请作者 Rebase 至最新 main 并补充对应单元测试与插件文档说明；若倾向 uint64 或移除恒定 fd_max 指标，请指导作者调整实现路径。合并前需完成代码同步、CI 验证及破坏性变更的发布说明。
