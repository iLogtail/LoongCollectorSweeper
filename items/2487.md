## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 指标因 float64 精度限制导致的数据失真问题。当前 main 分支仍使用 ParseFloat 解析，缺陷尚未修复。由于将指标类型从数值改为字符串可能影响下游监控系统的聚合与类型假设，需维护者进行兼容性评估或考虑改用 uint64/int64 方案。PR 逻辑清晰且具实际价值，建议保持开启等待审查。

## Best Possible Solution

保持开启等待维护者审查。建议维护者评估下游对指标类型变更（数值转字符串）的兼容性；若需保留数值语义，可建议作者改为 uint64/int64 实现，或采纳移除 fd_max 常量的备选方案。请作者 Rebase 至最新 main 并补充相关单元测试，CI 通过后合并。
