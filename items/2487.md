## Summary

本 PR 提议将 metric_system_v2 插件的 fd_allocated 与 fd_max 指标从 float64 改为字符串上报，以解决 int64 最大值超出 float64 精度范围的问题。由于指标数据类型变更属于破坏性修改，可能影响下游监控系统的兼容性与聚合查询，且 PR 正文也提出了移除 fd_max 常量的替代方案，需维护者进行架构评估与决策。当前证据不足以直接关闭，建议保持开启等待维护者审查。

## Best Possible Solution

保持开启并等待维护者审查。建议：1. 评估下游监控系统对指标类型变更（数值转字符串）的兼容性影响；2. 若需保留数值语义，可探讨底层是否支持 int64/uint64 上报，或采纳 PR 正文建议直接移除恒定的 fd_max 指标；3. 请作者 Rebase 至最新 main 分支，补充相关单元测试与兼容性说明，待 CI 通过后合并。
