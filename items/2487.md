## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 与 fd_allocated 指标因 float64 精度限制导致的大整数截断问题，提议改为字符串上报。当前 main 分支尚未合并此变更，且指标类型变更涉及下游兼容性评估与基线同步，需维护者审查决策，故保持开启。

## Best Possible Solution

建议维护者审查本 PR 的指标类型变更（float64 转 string）对下游消费端的兼容性影响。若确认可行，请作者 Rebase 至最新 main 分支，补充/更新相关单元测试后合并。若下游强依赖数值类型，可评估改用 int64/uint64 上报，或采纳 PR 正文中移除恒定 fd_max 指标的替代方案。
