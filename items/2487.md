## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 指标因 float64 解析导致的精度丢失问题，具有明确的修复价值。但将指标类型从数值改为字符串属于潜在破坏性变更，可能影响下游时序数据库、告警规则与仪表盘的兼容性。当前 main 分支尚未合并此修复，且 PR 仍需维护者评估类型变更影响或考虑改用 uint64 保留数值语义，故保持开启等待审查与后续迭代。

## Best Possible Solution

保持开启等待维护者审查。建议维护者确认下游数据管道对指标类型变更（float64 转 string）的兼容性；若需保留数值语义以便聚合计算，可评估改为 uint64 实现。请作者 Rebase 至最新 main，补充大整数精度单元测试，CI 通过后由维护者合并或调整方案。
