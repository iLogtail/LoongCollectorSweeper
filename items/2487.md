## Summary

本 PR 修复了 metric_system_v2 插件中 fd_max 指标因 float64 精度限制导致的大数值丢失问题，提议改为 string 类型上报。该变更涉及下游监控系统的指标类型兼容性（破坏性变更），且技术路径（string vs uint64 vs 移除常量）尚待维护者评估裁决，当前 main 分支仍未合并此修复或替代方案，故保持开启。

## Best Possible Solution

保持开启等待维护者技术裁决。建议维护者评估下游兼容性：若数据管道支持 uint64，优先改为 uint64 以保留数值语义；若必须使用 string，需补充破坏性变更说明与插件文档更新。请作者 Rebase 至最新 main，补充对应单元测试，并在 CI 通过后由维护者合并。
