## Summary

本 PR 提出将 fd_allocated 与 fd_max 指标从 float64 改为字符串上报，以修复大整数精度丢失问题。当前 main 分支仍存在该缺陷，但指标类型变更涉及下游监控系统兼容性，需维护者评估决策。

## Best Possible Solution

保持开启等待维护者审查。建议评估下游对指标类型变更（数值转字符串）的兼容性影响；若需保留数值语义，可探讨改用 int64/uint64 上报或按需移除该常量指标。请作者 Rebase 至最新 main 分支，补充相关单元测试，待 CI 通过后合并。
