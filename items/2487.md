## Summary

本 PR 提议将 metric_system_v2 插件的 fd_allocated 与 fd_max 指标类型由 float64 改为 string 以修复大整数精度丢失问题。由于指标类型变更属于破坏性更新，可能影响下游监控系统的数值解析与告警规则，且作者正文中主动提出了改用 uint64 或直接移除恒定 fd_max 的替代方案，当前技术路径与产品边界尚未定论。保守评估建议保持开启，等待维护者进行兼容性评估与技术裁决。

## Best Possible Solution

维护者需评估 float64 转 string 对下游监控系统的兼容性影响。若确认采用 string 方案，请作者 Rebase 至最新 main 分支，补充或更新对应单元测试，并更新插件文档说明类型变更；若倾向 uint64 或移除恒定 fd_max 的替代方案，请指导作者调整实现。当前保持开启等待技术裁决与代码同步。
