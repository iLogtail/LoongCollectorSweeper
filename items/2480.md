## Summary

本 Issue 咨询在使用 custom_single_flatten 转换器时如何输出纳秒级时间戳。用户已配置全局 EnableTimestampNanosecond: true，但 Kafka 输出仍为秒级。经核查，当前转换器序列化逻辑未自动透传全局纳秒开关，亦无独立的时间精度配置参数，属于有效的配置咨询与功能增强需求。

## Best Possible Solution

建议维护者或贡献者在 custom_single_flatten 转换器配置中新增 TimestampPrecision 或 TimeFormat 参数，以支持纳秒/微秒/毫秒/秒的灵活输出；或更新配置文档明确全局精度开关与转换器输出格式的边界。在功能实现或文档明确前，保持开启以跟踪该增强需求。用户可暂时通过自定义 Processor 在输出前手动处理高精度时间字段作为临时方案。

## Evidence

- **global_config_scope:** EnableTimestampNanosecond 为全局配置项，主要控制采集端内部 LogEvent 时间精度，但不同 Flusher/Converter 的序列化行为需单独适配。
  - file: [pkg/common/global.go](https://github.com/alibaba/loongcollector/blob/f1b84ba7c90f2a759c9aed572ba67c4c2facce68/pkg/common/global.go)
  - sha: [f1b84ba7c90f](https://github.com/alibaba/loongcollector/commit/f1b84ba7c90f2a759c9aed572ba67c4c2facce68)
- **converter_behavior:** custom_single_flatten 转换器当前实现未自动读取全局纳秒开关，缺少显式精度控制参数，导致输出仍为秒/毫秒级。
  - file: [pkg/protocol/converter/converter_custom_single_flatten.go](https://github.com/alibaba/loongcollector/blob/f1b84ba7c90f2a759c9aed572ba67c4c2facce68/pkg/protocol/converter/converter_custom_single_flatten.go)
  - sha: [f1b84ba7c90f](https://github.com/alibaba/loongcollector/commit/f1b84ba7c90f2a759c9aed572ba67c4c2facce68)
