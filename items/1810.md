## Summary

本 Issue 请求为内置 Loki Flusher 增加对 Grafana Loki 结构化元数据（Structured Metadata）的支持，需求明确且提供了官方 API 规范与文档参考。当前 main 分支实现尚未包含该特性，属于合理且可执行的插件功能增强，建议保持开启以待社区或维护者实现。

## Best Possible Solution

建议在 plugins/flusher/loki 中新增配置项（如 StructuredMetadataKeys），允许用户指定需提取为结构化元数据的日志字段。在序列化推送载荷时，将匹配字段组装为 JSON 对象并附加至 values 数组的第三项。实现需同步更新插件配置文档与单元测试。维护者可评估后分配里程碑或接受社区 PR。

## Evidence

- **implementation_gap:** 当前 main 分支的 Loki Flusher 在构建推送载荷时仅组装 [timestamp, log_line] 二维数组，未提供解析日志字段并附加为第三项结构化元数据对象的配置项或序列化逻辑，与 Issue 请求的 Loki HTTP API 规范存在明确差距。
