## Summary

本 Issue 请求为内置的 Loki Flusher 插件增加对 Grafana Loki 结构化元数据（Structured Metadata）的支持，允许在推送载荷的 values 数组第三项附加高基数字段。需求边界清晰，提供了明确的 API 规范与官方文档参考，且当前 main 分支的 flusher_loki 实现尚未包含该特性。属于合理且可执行的插件功能增强，无替代工单或关联 PR，符合保持开启条件。

## Best Possible Solution

建议在 plugins/flusher/loki 中新增配置项（如 StructuredMetadataKeys），允许用户指定需提取为结构化元数据的日志字段。在序列化推送载荷时，将匹配字段组装为 JSON 对象并附加至 values 数组的第三项。实现需同步更新插件配置文档、增加单元测试覆盖高基数元数据场景。建议维护者评估后分配里程碑或接受社区 PR。

## Evidence

- **feature_spec:** Issue 提供了明确的 Loki HTTP API 载荷示例与官方文档参考，需求指向高基数标签查询场景，具备直接的可实施性。
- **implementation_gap:** 当前 main 分支的 plugins/flusher/loki 插件在构建推送载荷时，仅组装 [timestamp, log_line] 二维数组，未提供解析日志字段并附加为第三项结构化元数据对象的配置项或序列化逻辑。
