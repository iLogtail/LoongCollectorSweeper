## Summary

本 Issue 请求为内置 Loki Flusher 增加对 Grafana Loki 结构化元数据（Structured Metadata）的支持。经核查当前 main 分支代码，flusher_loki 插件在构建推送载荷时仅生成包含时间戳与日志内容的二维数组，尚未实现将指定日志字段提取为 JSON 对象并附加至 values 数组第三项的逻辑。该需求明确合理，属于有效功能增强，需维护者评估优先级或社区贡献实现。

## Best Possible Solution

保持开启。建议维护者评估该特性优先级，或等待社区贡献 PR。实现路径可参考上游 Loki API 规范，在 flusher_loki 插件中新增配置项（如 StructuredMetadataKeys），用于指定需提取为元数据的日志字段，并在构建推送载荷时将其序列化为 JSON 对象附加至 values 数组第三项。需同步补充单元测试与插件配置文档。

## Evidence

- **implementation_gap:** 当前 flusher_loki 插件序列化日志时仅支持 [timestamp, log_line] 格式，未包含结构化元数据字段，与 Issue 请求的 Loki API 规范存在明确差距。
