## Summary

本 Issue 请求为内置 Loki Flusher 增加对 Grafana Loki 结构化元数据（Structured Metadata）的支持，允许在推送日志时附加高基数标签作为 values 数组的第三项。经核查当前 main 分支代码，该特性尚未实现，属于合理的功能增强请求，需维护者评估或社区贡献 PR。

## Best Possible Solution

保持开启。建议在 plugins/flusher/loki 中新增配置项（如 StructuredMetadataKeys），在序列化日志载荷时提取指定字段构建元数据 JSON 对象，并同步更新插件文档与单元测试。等待维护者排期或接受社区 PR。

## Evidence

- **implementation_gap:** 当前 main 分支的 Loki Flusher 在构建推送载荷时仅组装 [timestamp, log_line] 二维数组，未提供解析日志字段并附加为第三项结构化元数据对象的配置项或序列化逻辑，与 Issue 请求的 Loki HTTP API 规范存在明确差距。
