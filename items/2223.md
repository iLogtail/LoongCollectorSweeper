## Summary

本 Issue 明确请求提供 LoongCollector 在 Kubernetes Sidecar 模式下的官方部署用例与防日志丢失最佳实践。经核查当前 main 分支文档与示例，Kubernetes 部署指南仍主要聚焦 DaemonSet 模式，尚未补充 Sidecar 模式的标准配置、优雅退出（preStop）指导及 checkpoint 持久化建议。该需求属于仓库文档与示例维护范畴，具有明确价值且未被实现或替代，故保持开启。

## Best Possible Solution

建议维护者或贡献者在 docs/cn 与 docs/en 的 Kubernetes 部署指南中新增 Sidecar 模式章节，提供标准 Pod YAML 模板（含 emptyDir 共享卷、日志路径映射、资源限制）及防丢日志最佳实践（如 preStop 延迟退出、checkpoint 持久化配置）。同时更新示例镜像为官方 loongcollector 镜像。待相关文档或示例 PR 合并后即可关闭本 Issue。
