## Summary

本 Issue 请求将容器基础镜像从已停更的 CentOS 7 迁移至受维护的发行版以修复 CVE。维护者已确认该需求并正在推进，但明确指出受限于 glibc 版本兼容性与 GCC 9 工具链依赖，迁移工作存在技术阻塞。当前上下文与讨论未显示该变更已合入 main 分支或由其他 PR 完全解决，属于有效的核心构建与安全维护任务，需保持开启以跟踪进展。

## Best Possible Solution

继续推进基础镜像迁移工作。建议采用多阶段构建策略：构建阶段使用包含 GCC 9+ 的镜像（如 Ubuntu 20.04/22.04 或 Alibaba Cloud Linux 3）以解决编译依赖；运行阶段使用轻量级镜像（如 Distroless 或 Alpine）并通过静态链接或 glibc 兼容层确保二进制文件在目标环境正常运行。待新 Dockerfile 合入 main、CI 流水线验证通过并随正式版本发布后，再关闭本 Issue。
