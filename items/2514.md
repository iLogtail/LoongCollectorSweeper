## Summary

本 Issue 请求为 flusher_kafka_v2 增加本地磁盘缓存（DiskBuffer）能力以提升网络或 Kafka 异常时的灾备可靠性。经核对当前 main 分支源码与讨论记录，该插件及核心管道仍主要依赖内存队列与 Checkpoint 机制，尚未内置磁盘落盘缓冲功能。维护者已明确认可该需求并邀请社区贡献。属于合理且待实现的核心增强特性，证据充分，应保持开启以跟踪后续实现。

## Best Possible Solution

保持开启以跟踪该增强需求。建议维护者添加 help wanted 标签吸引社区贡献。贡献者可基于现有 Queue/Buffer 架构设计磁盘落盘方案，或为 flusher_kafka_v2 实现独立的本地缓存模块与刷盘策略并提交 PR。在功能落地前，用户可通过调大内存队列参数、优化 Checkpoint 间隔或结合外部可靠传输组件作为临时缓解措施。
