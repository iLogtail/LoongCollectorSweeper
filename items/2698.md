## Summary

本 PR 针对 #557 报告的 Linux 系统启动时间计算漂移问题提供了明确的修复方案。通过新增 GetBootTimeFromProcStat 优先读取 /proc/stat 的 btime 字段，消除了原 /proc/uptime 截断导致的 0~1 秒误差，并保留了合理的 fallback 逻辑与单元测试覆盖。代码已使用 std::istringstream 处理空白字符，属于有效且高质量的实现候选，需等待 CI 验证与维护者复核合并。

## Best Possible Solution

保持开启以待 CI 通过与维护者代码审查。建议维护者确认 /proc/stat 解析边界条件及日志输出符合规范后合并。合并后 GitHub 将自动关闭关联 Issue #557。
