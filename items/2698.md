## Summary

本 PR 针对 Issue #557 报告的系统启动时间漂移问题，提供了基于 /proc/stat btime 的优先读取方案，并保留了原有 fallback 逻辑与单元测试。自动化审查已指出 SplitString 在处理连续空格时可能产生空 token 导致解析失败的边界缺陷。该 PR 为有效贡献且正在活跃审查中，需作者根据反馈调整解析实现并补充边界测试，故应保持开启。

## Best Possible Solution

根据审查反馈将 SplitString 替换为支持空白折叠的解析器（如 StringSpliter），补充多空格边界测试用例。待 CI 通过及维护者复核后合并，以彻底修复 #557。
