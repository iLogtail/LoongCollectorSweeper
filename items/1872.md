## Summary

本 PR 提出了通过 AVX2 SIMD 指令优化多行日志解析性能的有效方向，但当前实现存在关键逻辑缺陷与构建兼容性问题，且存在合并冲突与未签署 CLA 的状态。属于可能仍有价值的陈旧 PR，建议保持开启以待原作者修复或社区接管。

## Best Possible Solution

保持开启并建议维护者添加 help wanted 标签。后续需修复 LogFileReader.cpp 中 SIMD 逆向扫描的头部标量回退逻辑（确保不足 32 字节时正确回退）；将 CMakeLists.txt 全局 -march=haswell 改为目标级编译选项或结合运行时 CPUID 动态分发以保障跨架构兼容；解决合并冲突并签署 CLA。若原作者无法继续，欢迎社区基于此思路提交新 PR 接管。

## Evidence

- **simd_logic_bug:** LogFileReader.cpp 中 SIMD 逆向扫描循环结束后，若未找到换行符，代码直接跳过 #else 标量回退逻辑，导致头部剩余数据（不足32字节）未被检查。审查评论已明确指出此问题。
  - file: [core/file_server/reader/LogFileReader.cpp:2200](https://github.com/alibaba/loongcollector/blob/46e9a4c4c7c88915cfffdb83100cb4147e2e6e5d/core/file_server/reader/LogFileReader.cpp#L2200)
  - sha: [46e9a4c4c7c8](https://github.com/alibaba/loongcollector/commit/46e9a4c4c7c88915cfffdb83100cb4147e2e6e5d)
- **cmake_arch_compat:** CMakeLists.txt 在检测到编译器支持 AVX2 时，全局追加 -march=haswell 到 CMAKE_CXX_FLAGS。这将导致整个二进制文件依赖 AVX2 指令集，在不支持该指令集的 CPU 上运行时会触发 Illegal Instruction 崩溃。
  - file: [core/CMakeLists.txt:60](https://github.com/alibaba/loongcollector/blob/46e9a4c4c7c88915cfffdb83100cb4147e2e6e5d/core/CMakeLists.txt#L60)
