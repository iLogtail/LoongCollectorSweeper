## Summary

本 Issue 报告了 v2 架构下 input_file 与 flusher_http 组合使用时的转换器兼容性问题（unsupported event type 3）。经核对 Epic #2595 进度与源码上下文，该报错属于 v2 Pipeline 演进阶段的已知核心能力缺口，flusher_http 的 Converter 尚未适配 v2 新事件类型（类型 3）。相关适配工作（B3/B4/C1 步骤）仍在进行中，非插件生态问题或仓库外事务，且报告清晰可复现，故保持开启。

## Best Possible Solution

保持开启并关联至 Epic #2595。维护者应在 B3/B4/C1 步骤中补齐 flusher_http 对 v2 新事件类型（Type 3）的转换支持。短期内建议在本 Issue 回复已知限制说明，并提供临时 Workaround（如暂使用 StructureType: v1，或改用已适配 v2 的 flusher_sls/flusher_stdout 验证链路）。后续需补充 flusher_http Converter 对 raw/custom 编码逻辑的处理及 E2E 测试。
