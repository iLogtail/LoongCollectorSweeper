## Summary

本 Issue 报告了 v2 架构下 flusher_http 转换器不支持 event type 3 (PipelineEventGroup) 导致日志丢弃的有效缺陷。经核对 Epic #2595 阶段 2 任务清单，相关 Flusher v2 多事件类型适配（B4/B5）尚未完成合并，当前 main 分支仍缺乏对该事件类型的转换支持。该问题属于核心管线演进路线中的已知兼容缺口，需等待后续 PR 实现适配。

## Best Possible Solution

保持开启以跟踪 flusher_http 对 v2 PipelineEventGroup (event type 3) 的转换适配工作。建议维护者推进 Epic #2595 阶段 2 中 B4/B5 相关任务。在核心适配完成前，用户可临时使用 StructureType: v1 或调整 Convert 协议/Encoding 组合规避。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试。
