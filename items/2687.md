## Summary

本 Issue 报告了 v2 架构下 native input_file 与 Go flusher_http 组合因转换器不支持 event type 3 (PipelineEventGroup) 导致日志丢弃的问题。该问题属于 Epic #2595 阶段 2 明确规划的 Flusher v2 多事件类型适配范围，当前 main 分支尚未完成该兼容改造，属于已知的核心架构演进缺口，需保持开启以跟踪修复进度。

## Best Possible Solution

保持开启并关联至 Epic #2595 阶段 2。维护者需在 B4/B5 步骤中为 plugins/flusher/http/ 的 Converter 补齐对 v2 PipelineEventGroup (event type 3) 的解析与转换逻辑。修复发布前，建议用户临时降级使用 StructureType: v1 或移除 Convert 配置段以规避数据丢弃。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试验证。
