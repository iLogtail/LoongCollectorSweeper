## Summary

本 Issue 报告了 v2 架构下 flusher_http 转换器尚未支持 PipelineEventGroup（event type 3）导致日志丢弃的有效缺陷。该问题属于核心管线演进路线（Epic #2595 阶段 2 任务 B4/B5）中的已知兼容缺口，当前 main 分支确实缺乏对应处理分支。报告清晰、可复现，且与项目架构迁移目标直接相关，需保持开启以跟踪后续适配工作。

## Best Possible Solution

保持开启以跟踪 flusher_http 对 v2 PipelineEventGroup 的转换适配工作。建议维护者结合 Epic #2595 阶段 2 推进 B4/B5 相关任务，在 flusher_http 转换器中补充对 event type 3 的解析与序列化逻辑。在核心适配完成前，用户可临时使用 StructureType: v1 或调整 Convert 协议规避。后续合并适配代码后需补充 v2 模式下 HTTP flusher 的 E2E 测试。
