## Summary

本 Issue 报告 v2 架构下 input_file 与 flusher_http (Convert raw) 组合运行时抛出 unsupported event type 3 导致日志全量丢弃。经核对 Epic #2595 演进路线与当前 main 分支状态，该问题属于阶段 2 步骤 B4/B5 明确规划的 Flusher v2 多事件类型适配范围，当前转换器尚未兼容 v2 PipelineEventGroup 结构。PR #2620 (A1) 仅重构配置解析约束，明确不保证运行时数据可达。此为已知的核心架构演进缺口，需保持开启以跟踪官方兼容修复进度。

## Best Possible Solution

保持开启并关联至 Epic #2595 阶段 2。维护者需在 B4/B5 步骤中为 plugins/flusher/http/ 的 Converter 补齐对 v2 PipelineEventGroup (event type 3) 的解析与转换逻辑。修复发布前，建议用户临时降级使用 StructureType: v1 或移除 Convert 配置段以规避数据丢弃。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试验证。
