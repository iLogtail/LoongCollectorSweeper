## Summary

本 Issue 报告了 v2 架构下 flusher_http 转换器未适配 PipelineEventGroup 多事件类型（event type 3）导致日志丢弃的真实缺陷。该问题与 Epic #2595 阶段 2 待办项（B4/B5）高度吻合，属于已知架构演进路线中的核心兼容性问题，需保持开启以跟踪修复进度。

## Best Possible Solution

保持开启并关联至 Epic #2595。维护者需在阶段 2 步骤 B4/B5 中为 flusher_http 的 Converter 补齐对 v2 PipelineEventGroup 多事件类型的解析与转换逻辑。修复发布前，可建议用户临时使用 StructureType: v1 或移除 Convert 配置段以绕过数据丢弃问题。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试验证。

## Evidence

- **issue_report:** Issue 正文提供了完整复现配置与错误日志，明确指向 flusher_http.go 转换器在 v2 模式下遇到 event type 3 时丢弃数据。
- **epic_alignment:** Epic #2595 阶段 2 明确列出 B4/B5 任务，要求补齐 Flusher/Processor 对多事件类型的支持，并禁止仅假定 Events[0] 为 Log，与本 Issue 报告的核心缺陷完全一致。
- **maintainer_comment:** 仓库 MEMBER 在评论区确认该问题为 v2 架构演进中的已知兼容性问题，明确建议保持开启以跟踪修复进度。
