## Summary

本 Issue 报告了 v2 架构下 input_file 与 flusher_http (Convert raw) 组合时因 Converter 未适配新事件类型（type 3）导致日志丢弃的有效缺陷。当前 main 尚未完成对该场景的完整支持，属于 Epic #2595 演进路线中的已知待办项，需保持开启以跟踪修复进度。

## Best Possible Solution

保持开启并关联至 Epic #2595。该问题属于 v2 Pipeline 演进路线中 B 线的已知适配缺口（flusher_http Converter 尚未支持 v2 多事件类型）。建议维护者在后续 B4/B5 步骤中补齐转换逻辑，并通过 E2E 验证后关闭。短期可建议用户暂用 StructureType: v1 或调整 Convert 协议组合绕过。

## Evidence

- **epic_tracking:** Epic #2595 阶段 2 中 B4/B5/B6 步骤仍为未勾选状态，明确表明 Go 插件对 v2 多事件类型的转换与导出支持尚未完成，本 Issue 为该演进路线上的有效阻塞反馈。
- **error_source:** 报错 unsupported event type 3 直接指向 flusher_http 的 Converter 逻辑未处理 v2 PipelineEventGroup 中的新事件类型，属于核心代码适配缺口，非配置错误或外部问题。
