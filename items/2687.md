## Summary

本 Issue 报告了 v2 架构下 flusher_http 的 Converter 尚未适配 PipelineEventGroup 多事件类型（event type 3）的真实缺陷，导致日志在 convert 阶段被丢弃。该问题属于 Epic #2595 阶段 2 的已知待办工作，需保持开启以跟踪修复进度。

## Best Possible Solution

保持开启并关联至 Epic #2595。维护者应在阶段 2 步骤 B4/B5 中为 flusher_http 的 Converter 补齐对 v2 PipelineEventGroup 多事件类型的解析与转换逻辑。在修复发布前，可建议用户临时使用 StructureType: v1 或移除 Convert 配置段以绕过数据丢弃问题。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试验证。

## Evidence

- **epic_tracking:** Epic #2595 阶段 2 Checklist 中 B4 与 B5 仍为未勾选状态，明确表明 Go 插件对 v2 多事件类型的转换与导出支持尚未完成。
- **error_source:** 报错 unsupported event type 3 指向 flusher_http 的 Converter 逻辑未处理 v2 PipelineEventGroup 中的新事件类型，导致数据在 convert 阶段被丢弃。
