## Summary

本 Issue 报告了 v2 架构下 input_file 与 flusher_http (Convert raw) 组合时，因 Converter 未适配 v2 新事件类型（type 3）导致日志全部丢弃的有效缺陷。该问题直接关联 Epic #2595 阶段 2 的插件迁移与 E2E 验证进度，属于核心管线演进的已知阻塞项，需保持开启以跟踪修复。

## Best Possible Solution

保持开启并关联至 Epic #2595。建议维护者在后续阶段 2（B4/B6）中补齐 flusher_http Converter 对 v2 事件类型 3 的解析与转换逻辑，并补充对应 E2E 测试。短期可建议用户暂用 StructureType: v1 或移除 Convert 段使用默认协议绕过。待核心适配完成并验证后关闭。

## Evidence

- **epic_tracking:** Epic #2595 阶段 2 中 B4/B5/B6 步骤仍为未勾选状态，明确表明 Go 插件对 v2 多事件类型的转换与导出支持尚未完成，本 Issue 为该演进路线上的有效反馈。
- **error_source:** 报错 unsupported event type 3 直接指向 flusher_http 的 Converter 逻辑未处理 v2 PipelineEventGroup 中的新事件类型，属于核心代码适配缺口。
