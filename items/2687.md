## Summary

本 Issue 报告了 v2 架构下 input_file 与 flusher_http 组合使用时，Converter 未能适配新事件类型（Type 3）导致日志丢弃的真实缺陷。该问题属于 v2 演进过程中的已知适配缺口，已由 Epic #2595 跟踪，需核心或插件代码适配，不符合自动关闭条件。

## Best Possible Solution

保持开启并关联至 Epic #2595。维护者应在后续演进步骤中补齐 flusher_http Converter 对 v2 事件类型的 raw/custom 协议转换支持。短期内可回复已知限制说明，并提供临时 Workaround（如暂使用 StructureType: v1 或调整 Convert 协议组合）。后续需补充对应 E2E 测试与转换逻辑验证。

## Evidence

- **issue_report:** 用户提供了完整的 v2 最小复现配置与 go_plugin.LOG 报错日志，明确指出 flusher_http Converter 在 Protocol: raw + Encoding: custom 组合下报错 unsupported event type 3 并丢弃数据。该行为与 Epic #2595 中 v2 多事件类型适配进度一致，属真实缺陷。
