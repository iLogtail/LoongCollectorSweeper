## Best Possible Solution

保持开启并关联至 Epic #2595 阶段 2（步骤 B4/B5）。维护者需在后续 PR 中为 plugins/flusher/http/ 的 Converter 补齐对 v2 PipelineEventGroup 事件结构的解析逻辑。修复前建议用户临时使用 StructureType: v1 或调整 Convert 配置规避。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试。
