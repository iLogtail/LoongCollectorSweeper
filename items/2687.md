## Summary

本 Issue 报告了 v2 架构下 flusher_http 转换器不支持 event type 3 (PipelineEventGroup) 导致日志丢弃的有效缺陷。该兼容缺口属于已知架构演进路线（Epic #2595 阶段 2）中的待实现项，需核心代码适配。当前 main 尚未合并相关修复，且无其他开放 PR 直接解决此问题，故保持开启以跟踪后续 Flusher v2 多事件类型适配工作。

## Best Possible Solution

保持开启以跟踪 flusher_http 对 v2 PipelineEventGroup (event type 3) 的转换适配工作。该需求已明确纳入 Epic #2595 阶段 2 路线。在核心适配完成前，建议用户临时使用 StructureType: v1 或调整 Convert 协议/编码组合规避。后续需由维护者推进 Flusher v2 多事件类型解析逻辑的 PR，并补充 v2 模式下 HTTP flusher 的 E2E 测试。
