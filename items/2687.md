## Summary

本 Issue 报告了 v2 架构下 flusher_http 转换器未适配 PipelineEventGroup 多事件类型（event type 3）导致日志丢弃的真实缺陷。该问题与 Epic #2595 阶段 2 待办项（B4/B5）高度吻合，属于已知架构演进路线中的核心兼容性问题，当前 main 分支尚未完成相关 Flusher 的 v2 适配，需保持开启以跟踪修复进度。

## Best Possible Solution

保持开启并关联至 Epic #2595。维护者需在阶段 2 步骤 B4/B5 中为 flusher_http 的 Converter 补齐对 v2 PipelineEventGroup 多事件类型的解析与转换逻辑。修复发布前，可建议用户临时使用 StructureType: v1 或移除 Convert 配置段以绕过数据丢弃问题。后续需补充 v2 模式下 HTTP flusher 的 E2E 测试验证。

## Evidence

- **epic_tracking:** Epic #2595 阶段 2 任务 B4/B5 明确列出需补齐 Flusher/Processor 对多事件类型的支持，并禁止仅假定 Events[0] 为 Log。当前 Epic 清单中 B4/B5 状态为未勾选（open），证实该兼容性问题仍在规划与开发中，尚未合入 main。
- **error_source:** 报错 unsupported event type 3 源于 flusher_http 的 Converter 逻辑未处理 v2 架构新增的事件类型枚举，导致数据在 convert 阶段被丢弃。Issue 提供了完整的最小复现配置与错误堆栈，指向明确。
