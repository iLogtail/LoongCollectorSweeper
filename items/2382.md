## Summary

本 PR 为 metric input 与 aggregator 添加了 panic 自动重启机制，符合核心运行时稳定性需求。但由于基线严重落后存在合并冲突，且当前实现存在 exitFlag 数据竞态与 defer 中递归重试缺乏退避上限等架构风险，属于有核心价值但需重构的陈旧 PR，应保持开启等待作者或维护者推进。

## Best Possible Solution

建议作者或维护者先将本 PR 分支 rebase 至最新 main 解决冲突。重构 panic 重启逻辑：将重试机制移至外部调度循环或独立 watcher 中，引入最大重试次数限制与指数退避策略，避免在 defer recover 中直接递归调用。修复 exitFlag 同步问题（改用 atomic.Bool 或 channel），补充边界测试与配置说明后，请求维护者复审。
