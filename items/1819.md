## Summary

本 PR 旨在修复 RFC3164 syslog 解析中 TAG 字段未限制长度可能引发的越界问题，符合 RFC 规范。但修改直接作用于 external/ 目录下的 vendored 第三方库副本，且未补充对应的单元测试。鉴于涉及第三方依赖维护策略（Go Modules vs vendored 补丁）及测试覆盖缺失，当前不宜直接合并或关闭，需维护者进一步审查依赖管理方式并要求补充测试。

## Best Possible Solution

建议维护者确认 external/ 目录下第三方库的维护策略。若仍需本地维护 vendored 副本，请作者补充针对 TAG 长度超限（>32字符）及边界条件的单元测试，并验证重构后的解析逻辑未破坏现有合法日志格式；若项目已全面使用 Go Modules，建议引导作者向上游 jeromer/syslogparser 仓库提交修复，或通过 go.mod replace 指令引入。待测试覆盖完善且策略确认后，由维护者重新审查合并。
