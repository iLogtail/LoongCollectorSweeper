## Summary

本 PR 修复了 RFC3164 syslog 解析中 TAG 字段未限制长度可能导致的数组越界问题，方向正确。但修改直接作用于 external/ 目录下的第三方依赖副本，且未补充单元测试。涉及依赖管理策略与测试覆盖，需维护者介入评估，故保持开启。

## Best Possible Solution

建议维护者确认 external/ 目录下第三方库的维护策略。若项目已使用 Go Modules，应引导作者向上游 jeromer/syslogparser 提交修复并通过更新 go.mod 引入；若仍需本地维护 vendored 副本，请作者补充针对 TAG 长度超限（>32字符）及边界条件的单元测试。待测试完善且依赖策略确认后重新审查合并。
