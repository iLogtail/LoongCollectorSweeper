## Summary

本 PR 修复了 RFC3164 syslog 解析器中 TAG 字段未限制长度导致的数组越界问题，修改位于 external/ 目录下的第三方依赖副本。方向正确且符合 RFC 规范，但涉及 vendored 代码的补丁策略需维护者确认，且缺少边界条件单元测试。属于有价值的真实缺陷修复，建议保持开启等待维护者审查与测试补充。

## Best Possible Solution

建议维护者审查 external/ 目录的第三方代码维护策略。若允许本地补丁，请作者补充针对 TAG 长度超限（>32字符）及特殊字符边界的单元测试；若需走上游，请引导作者向 jeromer/syslogparser 提交 PR 或通过 go.mod replace 引入 fork。测试补齐且策略确认后即可进入合并流程。
