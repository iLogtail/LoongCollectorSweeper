## Summary

本 Issue 报告了在使用 flusher_kafka_v2 时因发送阻塞导致管道背压，进而触发 Aggregator 队列满告警并致使采集卡死的问题。报告基于 v3.1.4，缺乏卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈，且当前 main 分支未见针对该特定背压死锁的明确修复记录。属于核心流控与插件交互的真实缺陷报告，需维护者进一步排查或用户提供更多调试数据。

## Best Possible Solution

建议维护者保持本 Issue 开启以跟踪核心管道背压处理缺陷。下一步应引导用户升级至 v3.3.5 观察是否缓解，并在复现卡死时提供 goroutine dump 或 pprof 数据以精确定位阻塞调用栈。同时需审查 flusher_kafka_v2 的发送超时、重试与缓冲配置，评估是否需在内核流控模块增加防死锁熔断或快速失败策略。
