## Summary

本 Issue 报告了在使用 flusher_kafka_v2 时，因下游发送阻塞导致背压传导至 Aggregator，触发 loggroup queue is full 告警后采集流水线卡死的运行时缺陷。该问题涉及核心管道流控、队列满策略与外部组件交互，属于需深入排查的真实缺陷。当前 main 分支未见针对此特定背压死锁的明确修复，且 Issue 创建时间较短，日志与配置证据充分，保守评估应保持开启。

## Best Possible Solution

建议保持开启并等待维护者或贡献者跟进：1. 请用户提供卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈；2. 审查 flusher_kafka_v2 的发送超时、重试及异步实现，评估是否需引入非阻塞发送、队列满丢弃/降级策略或可配置的超时参数；3. 检查 Aggregator/PluginRunner 层的背压传导机制，确认队列满时的预期行为与死锁防护；4. 建议用户先升级至最新稳定版 v3.3.5 并调整 Kafka flusher 的缓冲/超时参数验证是否缓解。
