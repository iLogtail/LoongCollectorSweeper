## Summary

本 Issue 报告了在使用 flusher_kafka_v2 时因下游发送阻塞引发管道背压，导致 Aggregator 队列满告警并致使采集停滞的问题。该问题涉及核心流控机制与 Kafka 插件的超时重试策略，属于真实缺陷报告。当前 main 分支未见针对此背压死锁的明确修复，且缺少卡死时的 goroutine dump 以精确定位阻塞点，需保持开启以等待维护者排查或用户补充调试数据。

## Best Possible Solution

保持开启以跟踪核心管道背压处理缺陷。下一步应引导用户升级至最新版（v3.3.5）观察是否缓解，并在复现卡死时提供 goroutine dump 或 pprof 数据以精确定位阻塞调用栈。同时需维护者审查 flusher_kafka_v2 的发送超时、重试与缓冲配置，评估是否需在内核流控模块增加防死锁熔断或快速失败策略。
