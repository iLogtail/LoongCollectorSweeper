## Summary

本 Issue 报告了 flusher_kafka_v2 发送阻塞引发全局背压，导致 Aggregator 队列积压并卡死采集流水线的真实缺陷。当前 main 分支尚未实现针对此特定阻塞场景的自动丢弃、超时熔断或异步隔离策略，属于需维护者评估的核心可靠性问题。

## Best Possible Solution

建议维护者要求作者提供卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈；审查 flusher_kafka_v2 的同步发送逻辑、超时/重试配置及上游 Kafka 客户端版本；评估在 Aggregator 或 PluginRunner 层实现队列满丢弃策略、背压熔断或异步发送机制，避免单 Flusher 阻塞拖垮全局采集流水线。若确认为配置或上游客户端问题，可补充最佳实践文档或升级依赖。
