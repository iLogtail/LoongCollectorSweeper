## Summary

本 Issue 报告在使用 flusher_kafka_v2 时，因 Kafka 发送阻塞引发背压，导致 Aggregator 队列积压（loggroup queue is full）并最终卡死整个采集流水线。作者提供了详细的环境信息、YAML 配置及连续告警日志，并指出可能与 Kafka Producer 同步发送缺陷有关。

## Best Possible Solution

建议维护者要求作者提供卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈；重点审查 flusher_kafka_v2 的同步发送逻辑、超时/重试配置及上游 Kafka 客户端版本是否存在已知阻塞缺陷；评估在 Aggregator 或 PluginRunner 层实现队列满丢弃策略、背压熔断或异步发送机制。同时建议作者先升级至最新版本 v3.3.5 验证是否已包含相关背压优化或依赖升级。本 Issue 保持开启以待核心维护者介入排查。
