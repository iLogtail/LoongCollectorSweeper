## Summary

本 Issue 报告了在使用 flusher_kafka_v2 时，因底层发送阻塞导致 loggroup queue is full，进而引发采集流水线整体卡死的背压缺陷。问题描述清晰，附带完整配置与日志，属于核心链路流控与超时机制的真实缺陷，当前 main 分支尚无明确修复证据，需维护者进一步排查与介入。

## Best Possible Solution

保持开启。建议维护者：1. 审查 flusher_kafka_v2 的同步发送逻辑与底层 Kafka 客户端版本，确认是否存在已知阻塞缺陷；2. 评估在 Aggregator/Flusher 层引入发送超时、背压丢弃或熔断机制，避免队列满时反向阻塞 Processor 线程；3. 邀请用户提供卡死时的 goroutine dump 及完整 Kafka 配置以便精准定位。若确认为配置参数不当，可补充调优文档。
