## Summary

本 Issue 报告了 flusher_kafka_v2 发送阻塞导致管道背压传导至 Aggregator，引发 loggroup queue is full 告警并伴随采集卡死的现象。日志与配置完整，属于核心流控与插件交互的真实缺陷报告。当前报告基于 v3.1.4，缺乏卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈，且 main 分支尚未有针对该特定背压死锁的明确修复记录，不符合自动关闭条件。

## Best Possible Solution

建议维护者引导用户提供卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈；审查 flusher_kafka_v2 的发送超时、重试与缓冲配置是否支持快速失败或背压反馈机制；评估管道在 Flusher 长时间阻塞时的熔断或降级策略。用户可先尝试升级至 v3.3.5 并调整 Kafka producer 的 timeout 与 buffer 参数观察是否缓解。若确认为核心管道背压处理缺陷，需在内核流控模块增加防死锁或丢弃策略。
