## Summary

本 Issue 报告了在使用 flusher_kafka_v2 时因发送阻塞导致管道背压传导、Aggregator 队列满进而采集卡死的缺陷。问题现象明确，日志与配置完整，属于核心流控与插件交互的真实缺陷。当前 main 分支未见针对该 Kafka 发送阻塞或背压熔断机制的明确修复，且缺少卡死时的 goroutine dump 等深度调试数据，需维护者进一步排查或引导用户提供 pprof 信息，不符合自动关闭条件。

## Best Possible Solution

建议维护者要求用户提供卡死时的 goroutine dump 或 pprof 数据以精确定位阻塞调用栈；审查 flusher_kafka_v2 的发送超时、重试与缓冲配置是否支持快速失败或背压反馈；评估管道在 Flusher 长时间阻塞时的熔断或降级策略。用户可先尝试升级至 v3.3.5 并调整 Kafka producer 的 timeout 与 buffer 参数观察是否缓解。
