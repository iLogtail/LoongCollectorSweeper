## Summary

本 Issue 报告了 flusher_kafka_v2 因底层 Kafka Producer 发送阻塞引发背压，导致 loggroup queue is full 并卡死采集流水线的问题。日志与配置完整，作者已定位到可能与 Kafka 客户端已知缺陷相关。当前 main 分支尚未确认包含针对此阻塞/背压丢弃机制的明确修复，且涉及核心采集链路稳定性，需维护者进一步评估依赖版本与超时策略，故保持开启。

## Best Possible Solution

建议维护者：1. 核对 main 分支 go.mod 中 Kafka 客户端版本是否已修复该阻塞缺陷；2. 审查 flusher_kafka_v2 的发送逻辑，评估是否需引入发送超时、熔断或背压丢弃机制以避免阻塞整个 Pipeline；3. 邀请用户提供卡死时的 goroutine dump 及完整 Kafka 配置。若确认依赖升级已解决或需调整架构，可后续更新状态。
