## Summary

本 Issue 请求在 K8s 元数据处理中增加 ExternalK8sAnnotationsTag 参数以支持提取容器 annotations 作为日志标签。经核查，该功能属于合理的核心增强需求，维护者已明确欢迎社区贡献，且当前 main 分支尚未实现等效的 annotations 提取逻辑，故保持开启以跟踪开发进度。

## Best Possible Solution

保持开启作为功能需求跟踪。建议贡献者参考现有 ExternalK8sLabelTag 的实现路径，在 K8s 元数据 Processor（如 plugins/processor/k8smeta 或相关 K8s 采集插件）中扩展 annotations 匹配与标签注入逻辑。等待社区提交 PR 或维护者排期实现。

## Evidence

- **maintainer_endorsement:** 维护者在讨论区明确欢迎认领开发并提供支持，确认该特性属于项目接受的功能增强方向。
- **feature_not_implemented:** 当前 main 分支 K8s 元数据相关 Processor/插件配置中仅见 ExternalK8sLabelTag 参数，未见 ExternalK8sAnnotationsTag 或等效 annotations 提取逻辑的实现与文档。
